# API Design & Contract Skill

Use this skill when designing, documenting, or refactoring RESTful APIs, GraphQL schemas, or gRPC services.

## Capabilities & Workflow
1. **RESTful Best Practices**: Resource-oriented URLs, standard HTTP methods (GET, POST, PUT, PATCH, DELETE), and proper status codes (200, 201, 204, 400, 401, 403, 404, 422, 500).
2. **Schema & Validation**: Ensure strong request/response validation (Zod, TypeBox, Pydantic, OpenAPI).
3. **Error Handling**: Standardize RFC 7807 problem details error responses across all endpoints.
4. **Backward Compatibility**: Ensure non-breaking changes, deprecation strategies, and versioning protocols.
