# Performance & Resource Optimization Skill

Use this skill when profiling application speed, fixing memory leaks, or optimizing CPU/database bottlenecks.

## Capabilities & Workflow
1. **Algorithm & Time Complexity**: Identify O(N^2) loops, unnecessary re-renders, and inefficient data structures.
2. **Database & Queries**: Detect N+1 query problems, missing indexes, unpaginated queries, and inefficient joins.
3. **Memory Management**: Locate memory leaks, event listener leaks, and unclosed file/socket handles.
4. **Network & Bundle Optimization**: Optimize payload size, enable caching headers, lazy loading, and tree-shaking.
