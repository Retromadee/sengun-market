# Testing & Quality Assurance Skill

Use this skill when writing unit, integration, or end-to-end tests, or setting up test automation pipelines.

## Capabilities & Workflow
1. **Framework Detection**: Inspect project config (`package.json`, `Cargo.toml`, `pytest.ini`) to use existing test runners (Jest, Vitest, PyTest, Playwright, Node Test Runner).
2. **Test Strategy**:
   - **Unit Tests**: Test pure functions, edge cases, boundary conditions, and error paths.
   - **Integration Tests**: Test API endpoints, database interactions, and component boundaries.
   - **Mocking**: Mock external network calls and I/O while keeping business logic un-mocked.
3. **Execution & Coverage**: Run tests using project-specific flags and analyze coverage reports.
